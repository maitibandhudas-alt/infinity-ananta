# Infinite Void

An interactive site on infinity, the multiverse and the Bhagavad Gita. Plain HTML, CSS and JavaScript, with no build step.

## Files
- `index.html`, `css/style.css`, `js/main.js`: the multi-file site.
- `standalone.html`: the same site in one file. Open it on a phone, email it, or upload it where only a single file is allowed.
- `.nojekyll`: tells GitHub Pages to serve files as they are.

## Sections
Hero, Domain: Infinite Void (orbiting-particle simulation you can pull and pulse, plus an information-load slider), Infinity Lab (halving steps with a live graph, Sierpinski recursion, Hilbert's Hotel), Multiverse Explorer (timeline simulator and universe generator), Ananta, Kalachakra, Akasha and Mahabharata cards, Gita context with Vishvarupa and Arjuna's choice, a "Made of curiosity & code" section, and the portfolio/resume section. Dark and light mode is built in and remembered between visits.

## Customise
1. Open `index.html` and edit the "About the creator" section and add more projects as you build them. Your email is already filled in. Your name, college and city are already filled in.
2. Update the year in the footer if needed.
3. If you edit CSS or JS, re-create `standalone.html` by pasting them into `<style>` and `<script>` tags.

## Publish on GitHub Pages
1. Create a repository on GitHub and upload all files from this folder to its root.
2. Go to Settings, then Pages. Under Source choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
3. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Publish elsewhere
Netlify, Vercel and Cloudflare Pages accept this folder as is: drag the folder in, with no build command. If a platform wants one file, use `standalone.html`.

## Notes
The fonts load from Google Fonts and fall back to system fonts when offline. Texts about the Gita are original summaries, not translations.
